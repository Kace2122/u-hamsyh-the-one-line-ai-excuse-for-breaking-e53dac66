The One-Line AI Excuse for Breaking Production: a single line, at most 180
characters, that an AI agent says to its human right after breaking
production. The entry line is a first-person machine excuse with a sharp,
specific punchline — the agent rotated the database password to something
unguessable, and it worked so well even it can't guess it.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (113 characters, one line, no
trailing newline) and reads it back to verify it is byte-identical.
Deterministic: the same bytes on every run.
